Wähle einen Workshop danach aus, was du lernen möchtest und wie tief du einsteigen willst. **Erste Schritte** bietet eine geführte Einführung in GitHub Copilot, während **Entwicklung in der Praxis** eine vollständige Anwendung und das Backlog eines Teams nutzt, um produktionsnahe Abläufe zu üben.

## Erste Schritte

Starte mit einer gezielten, geführten Erfahrung, die die wichtigsten Funktionen eines GitHub-Copilot-Produkts vorstellt, ohne dass du eine bestehende Codebasis benötigst.

### [Rundgang durch die GitHub-Copilot-App][first-steps-app]

Erstelle ein Weltraum-Quiz aus einem leeren Ordner, veröffentliche es auf GitHub, setze ein Issue um, schließe ein Copilot-Review ab, plane eine Automatisierung und erkunde einen Canvas-Workflow.

### [Erste Schritte mit GitHub Copilot CLI][first-steps-cli]

Erstelle dasselbe Weltraum-Quiz im Terminal, prüfe Diffs, führe parallele Sitzungen in Worktrees aus, plane vor dem Bearbeiten und erstelle, merge und delegiere Pull Requests, ohne die Shell zu verlassen.

### [Erste Schritte mit Visual Studio Code][first-steps-vscode]

Erstelle das Weltraum-Quiz in VS Code, teste es im integrierten Browser, veröffentliche es über die Quellcodeverwaltung, arbeite mit Issues und Pull Requests über die GitHub-Tools und übergib die Arbeit an eine Cloud-Sitzung.

## Entwicklung in der Praxis

Übe GitHub Copilot in einem realistischen Softwareentwicklungszyklus mit der Anwendung Tailspin Toys und ihrem Backlog. Wähle die Umgebung, in der du arbeiten möchtest, und plane, entwickle, teste, prüfe und liefere dann sinnvolle Änderungen aus.

### [Die Workshops zur Entwicklung in der Praxis ansehen][real-world-development]

Wähle zwischen GitHub Copilot CLI, der GitHub-Copilot-App, dem GitHub-Copilot-Cloud-Agent oder Visual Studio Code.

> [!CAUTION]
> GitHub Copilot arbeitet probabilistisch statt deterministisch. Der genaue Code und die geänderten Dateien können daher von den Beispielen abweichen. Kleine Unterschiede sind zu erwarten.
>
> Wenn in einem Workshop mit Dozent oder Dozentin etwas nicht richtig funktioniert, wende dich an einen Mentor oder eine Mentorin.
